# Preview cleanup runbook

Preview resources are environment-scoped and use the `oraja-training-preview-`
prefix. The cleanup plan is generated by:

```sh
npm run preview:cleanup:plan
```

The plan is review-only. Deleting a preview D1 database, Durable Object
namespace, queue, or R2 bucket requires a separate operator approval and is
not performed by CI. Before approving a deletion, compare the exact resource
inventory with `wrangler.jsonc`, confirm the last Worker revision and
migration state, and retain the deployment record. Never pass a wildcard or
the production prefix to a cleanup command.
